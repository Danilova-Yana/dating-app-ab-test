# Анализ результатов A/B-тестирования

## О проекте

Проект посвящён анализу A/B-теста в дейтинговом приложении.

В рамках эксперимента для новых пользователей из нескольких стран была изменена стоимость премиум-подписки при покупке через две новые платёжные системы. Стоимость пробного периода оставалась без изменений.

**Цель:** оценить успешность эксперимента и влияние изменения стоимости подписки на ключевые продуктовые метрики.

## Стек

* Python: Pandas, NumPy, SciPy, Matplotlib, Seaborn
* Jupyter Notebook

## Данные

Для анализа использовались два набора данных:

* информация о пользователях;
* информация о транзакциях.

## Ход анализа

* провела исследовательский анализ данных о пользователях и транзакциях;
* очистила данные и исключила некорректные транзакции;
* проверила сопоставимость экспериментальных групп по полу, возрасту и стране с помощью статистических критериев;
* проанализировала типы продуктов и выделила `premium_no_trial`, для которого непосредственно изменялась стоимость;
* рассчитала ключевые продуктовые метрики: Conversion, ARPU и ARPPU;
* сравнила результаты тестовой и контрольных групп;
* проверила статистическую значимость различий;
* проанализировала выбросы и аномальные значения.

## Результаты

A/B-тест не подтвердил эффективность изменения стоимости премиум-подписки.

Повышение цены сопровождалось снижением конверсии, при этом устойчивого роста выручки на пользователя не наблюдалось. На основании результатов эксперимента изменение не было рекомендовано к внедрению.

## Рекомендации

Для дальнейшей оптимизации ценовой стратегии рекомендуется протестировать другие уровни стоимости подписки и дополнительно исследовать результаты в отдельных пользовательских сегментах.

## Потенциальная польза для бизнеса

Результаты анализа позволяют обоснованно отказаться от внедрения неэффективного изменения и избежать затрат ресурсов на его реализацию, а также определить направления для дальнейшего тестирования ценовой стратегии.

## Структура проекта

* `*.ipynb` — Jupyter Notebook с полным анализом и результатами;
* `users_*.csv` — данные о пользователях;
* `transactions_*.csv` — данные о транзакциях.
